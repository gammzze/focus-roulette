# 🎯 Focus Roulette

Rastgele bir konu çek, süreni belirle, odaklan ve öğrendiklerini not al.
Klasik/edebi bir arayüzle derinlemesine öğrenme deneyimi.

## Özellikler
- 🎡 **Konu çarkı** – 300+ konu arasından yavaşlayarak duran rastgele seçim
- ⏱ **Odak zamanlayıcı** – hazır süreler (5 / 15 / 25 / 45 dk), duraklat / bitir, ilerleme çubuğu
- 🔔 **Bildirim & ses** – süre dolunca tarayıcı bildirimi ve uyarı sesi, sekme başlığında geri sayım
- 📝 **Not defteri** – çalışırken not al, gerçekten çalıştığın süreyle arşive kaydet
- 📚 **Arşiv** – arama, kayıt silme, Markdown olarak dışa aktarma
- 📊 **İstatistikler** – toplam araştırma, odak süresi ve günlük seri
- ⌨️ Esc ile modalları kapatma, Enter ile süre başlatma

## Kullanım
Kurulum gerekmez — `index.html` dosyasını tarayıcıda açman yeterli.
Veriler tarayıcının `localStorage` alanında saklanır.

## Teknolojiler
HTML · CSS · Vanilla JavaScript
